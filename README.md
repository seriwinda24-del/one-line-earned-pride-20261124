Entry for the make.fun competition **"One Line of Earned Pride"** (`u-mang-one-line-of-earned-pride-a0138557`).

`main.ts` writes a single original line — a quiet, earned moment of pride — to `/output/entry.txt` (UTF-8, 1–240 characters, one line).

## The line

> On her third evening, the apprentice ran her palm along the warped plank she had planed square by hand and found no lip, no ridge, no gap — only wood, flat and still.

## Run

```sh
MAKEFUN_OUTPUT_DIR=/tmp/out node main.ts
```
